BiLSTM là gì?
Bidirectional Long Short-Term Memory

1. Từ RNN đến LSTM

RNN gặp vấn đề vanishing gradient. LSTM giải quyết bằng cơ chế cổng (gates):

  • Forget gate — quên thông tin cũ
  • Input gate — ghi thông tin mới
  • Output gate — xuất hidden state

📌 C_t = f_t ⊙ C_{t-1} + i_t ⊙ ĝ_t

2. Bidirectional LSTM

BiLSTM kết hợp hai LSTM chạy song song (xuôi + ngược), mỗi từ "thấy" toàn bộ ngữ cảnh:

Từ #1
→
Từ #2
→
Từ #3
Từ #3
→
Từ #2
→
Từ #1

✅ h_i = [→h_i; ←h_i] — ghép nối hidden state 2 chiều

BiLSTM + Softmax

P(tag | w_i) = softmax(W · h_i + b)

BiLSTM + CRF
Tối ưu hóa toàn bộ chuỗi nhãn

Ý tưởng CRF

CRF tính điểm cho toàn bộ chuỗi nhãn và chọn chuỗi tốt nhất:

score(y) = Σ emission(y_i|w_i) + Σ transition(y_{i-1}→y_i)

Transition Matrix

CRF học ma trận T[i,j]: xác suất chuyển nhãn i → j. Giá trị -9.99 ≈ -∞ = gần như không thể.

📌 O → I-PER = -9.99 → CRF sẽ không bao giờ chọn!

Viterbi Decode

Dynamic programming tìm chuỗi nhãn tối ưu: O(n × T²)

Đảm bảo BIO

1. Bộ lọc logic toàn cục

CRF là "bộ lọc hậu xử lý thông minh" nhúng trong training. Transition Matrix ép toàn bộ tối ưu hóa tuân thủ ràng buộc chuỗi.

✅ O → I-PER bị cho điểm rất thấp → Viterbi không bao giờ chọn

2. Toàn cục vs Cục bộ

  • Softmax: tối ưu từng vị trí → tham lam → sai ngữ cảnh
  • CRF: tối ưu toàn câu → hiểu ngữ cảnh tốt hơn

3. Kết luận

  • CRF tăng F1 từ 0.24 → 0.65 (+170%)
  • Loại bỏ hoàn toàn 403 lỗi BIO
  • GPE: 0.00 → 0.59, PER: 0.07 → 0.72

🏆 BiLSTM+CRF là kiến trúc vượt trội cho NER. CRF là thành phần cốt lõi.
